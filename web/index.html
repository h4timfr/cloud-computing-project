A city opens exactly one incident when its hysteresis-filtered class reaches WARNING or CRITICAL, escalates in place if it later reaches CRITICAL, and closes once the city is back to NORMAL — the record is kept as history either way.     Read routes used by this page: GET /zones, GET /zones/{zone_id}/history, GET /incidents. Ingestion (POST /readings) requires a shared secret and is never called from the browser.

    FloodPulse is a university cloud-computing project. Risk scores are deterministic heuristic-v1 values, clearly labelled as such and never presented as a prediction. Every metric carries a provenance tag: REAL comes from the external weather provider, MODEL is derived from those real fields, and SIM is generated by the FloodPulse simulator because no real sensor exists for it.

    heuristic-v1 is a hand-tuned deterministic scoring heuristic over sensor values. It is not a calibrated hydrological model, not a statistical forecast and not a machine-learning prediction, and it is not an official flood warning.

    Data & Methodology explains the provenance tags, the model and its limitations.
