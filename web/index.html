FloodPulse is a university cloud-computing project. Sensor data is simulated; risk scores are deterministic heuristic values, clearly labelled as such and never presented as a prediction.

Architecture: simulator → API Gateway → Lambda → DynamoDB → this static dashboard on S3. Ingestion endpoint POST /readings requires a shared secret; the dashboard's read routes do not.
